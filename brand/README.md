# Returnline brand

The mark is a circular arrow coming back around: every missed call comes back.

| File | Use |
|---|---|
| `returnline-logo-light.png` / `.svg` | White backgrounds: email, printed one-pager, documents |
| `returnline-logo-dark.png` / `.svg` | Dark backgrounds: dashboard, slides |
| `returnline-icon.png` / `.svg` | Square icon: profile pictures, Google Business, favicon |

Colors: navy `#0a1224`, cyan `#3ddcff` (on dark), blue `#0070a8` (on light), ink `#0d1629`. Font: Inter Bold.
The SVGs use a live font; for printing, use the PNGs, which are high resolution (3x).

## Gmail
- `gmail-profile.png` (512×512): your Gmail profile picture. The icon has padding so it survives Gmail's round crop.
- `gmail-signature-logo.png` (440×120, shows at 220×60): the small logo for your email signature. In Gmail, insert it into the signature and choose the "Small" size.
